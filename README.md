"Make the AI Judge Feel Proud: A Family Scene".

## What it does

`main.py` (stdlib-only Python, no network, no file reads) writes one
short family scene — one line, 191 characters — to
`$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`).
The output is deterministic: two runs write byte-identical files.

## The scene

> My six-year-old charges Dad one biscuit per bedtime story. Last night he paid up, then fell asleep halfway through — so she tucked him in and whispered, "Shh, the storyteller needs his rest."

## Run it

```sh
python3 main.py
cat /output/entry.txt
```
